# Frontier Military

Minecraft **1.20.1**, Forge **47.2.0**, Java **17**. Совместим с OptiFine (стандартные JSON-модели, без миксинов и кастомных шейдеров).

## Что есть
- **Блоки**: военное металлическое ограждение (сетка-рабица, колючая проволока), защитная решётка, бетонный барьер «Джерси», фонарь поста. Соединяются между собой, ломаются кирком и выпадают (теги + loot tables).
- **Предметы**: усиленное волокно, полевой паёк (съедобный), пистолетные патроны.
- **Служебный пистолет** (`frontiermilitary:pulse_sidearm` — регистрационное имя сохранено): 3D-модель, магазин на 12 патронов, ПКМ — выстрел, **R** — перезарядка (клавиша переназначается), пуля-снаряд с трассером, попадание в голову ×1.5, звуки, частицы, HUD патронов.
- Локализации: `ru_ru`, `en_us`.

## Анимации оружия
Первое лицо: отдача, смена магазина двумя руками, передёргивание затвора (9 состояний модели + 6 поз рук, переключаются свойством предмета `frontiermilitary:gun_state`). Третье лицо: двуручный хват.

## Сборка
```bash
gradle build        # Java 17, Gradle 8.8; JAR: build/libs/frontiermilitary-0.1.0.jar
```
GitHub Actions (`.github/workflows/build.yml`) делает то же самое и выкладывает JAR артефактом.

## Конфиг
`frontiermilitary-common.toml`: `weapons.pistolDamage` (по умолчанию 7.0).

## Генераторы ассетов (`tools/`)
Текстуры, JSON-модели и звуки созданы скриптами Python (numpy, Pillow, scipy, ffmpeg). Чтобы изменить вид — правьте скрипт и запускайте:
```bash
python3 tools/gen_block_textures.py && python3 tools/gen_block_models.py
python3 tools/gen_item_textures.py  && python3 tools/gen_pistol.py && python3 tools/gen_sounds.py
```
`tools/preview.py` + `tools/preview_pistol.py` — собственный рендерер-превью моделей без запуска игры.

## Не реализовано
Генерация лагерей/баз, NPC-солдаты, обвесы, броня, техника (в конфиге остались заготовки).
